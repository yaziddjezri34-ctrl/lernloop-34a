# LernLoop §34a Web Demo

Vercel-ready React/Vite Web-Demo.

## Inhalt

- 20 Demo-Fragen
- Single Choice
- Multiple Choice
- Kombinationsfragen
- Lernmodus mit Prüfen-Button
- Auswertung mit 60%-Bestehensgrenze
- Vollversion-Hinweis

## Lokal starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment auf Vercel

1. Projektordner zu GitHub hochladen
2. Auf vercel.com anmelden
3. "Add New Project"
4. Repository auswählen
5. Framework wird als Vite erkannt
6. Deploy klicken

Alternativ:
Vercel CLI nutzen:

```bash
npm install -g vercel
vercel
```
