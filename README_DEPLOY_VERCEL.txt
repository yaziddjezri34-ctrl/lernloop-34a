VERCEL DEPLOY ANLEITUNG
=======================

1. ZIP entpacken
2. Ordner "lernloop_34a_vercel_demo" öffnen
3. GitHub Repository daraus machen
4. Auf vercel.com anmelden
5. Add New Project klicken
6. Repository auswählen
7. Deploy klicken

Vercel erkennt automatisch:
Framework: Vite
Build Command: npm run build
Output Directory: dist

Nach dem Deploy bekommst du einen Link, z. B.:

https://lernloop-34a-demo.vercel.app
